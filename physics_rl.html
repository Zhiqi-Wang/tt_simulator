PART ONE

一、物理引擎

球、拍、台、网、人，全部用同一套刚体冲量模型；所有技术差异都落在可测量的物理量上。

1.1坐标系、球员与属性

右手系，单位米。球台长边是 x，网在 x=0，z 向上，地面 z=0。

x ∈ [−1.37, +1.37] // 台长 2.74 m，每边 HALF_L = 1.37
y ∈ [−0.7625, +0.7625] // 台宽 1.525 m
z = 0.76（台面） // 网高 0.1525 m
0 号球员在 x<0，1 号在 x>0

每个球员的观测和动作都在自己视角下：自己的前方永远是 +x，持拍手一侧永远是“右”。 前后方向乘 m = ±1（哪一边），横向再乘持拍手 hs = ±1： lat_m = m·hs，每分开始写入 T[LM0+j]。左手球员因此是右手球员在自己视角下的精确镜像， 同一个网络可以控制任意持拍手的球员。

人不是一个点：身体 + 持拍手

身体

  • 位置与速度各三维，前后/横向/高度三轴独立加速度控制；高度就是下蹲深浅。
  • “手”是身体之外的偏移：hand_off(blend) = −0.13 − 0.19·blend（自己视角）。
  • blend=+1 正手（手在持拍侧），−1 反手（手在身前偏另一侧），中间是切换途中。

正反手是一个有速度的状态量

  • 切换受 srate（敏捷、疲劳、上一拍技术的还原时间）限制。
  • 切换途中 awk 变大：挥拍速度下降、误差上升。
  • 所以“先动脚再动手”是划算的：站稳、切换完成再击球，球质明显更高。

1.2器材：持拍手、握法、胶皮

器材写在每名球员的属性向量里（S[HAND], S[GRIP], S[RFH], S[RBH]），物理和观测都会用到。 参数来自资料里各类胶皮的定性特征（反胶摩擦大、正胶颗粒朝外出球快、长胶颗粒易倒“倒转”来球、防弧表面不黏）， 再按碰撞模型标定成三个数。

胶皮怎么进入物理

  • 碰撞：racket_impact(v, ω, n, v_拍, e, μ, ks)，每板用这一面的胶皮参数。
  • 能做出的拍面倾角上限 rub_spin_cap = min(μ/√(1+μ²), 0.6·ks)：摩擦小就“搓不转、拉不转”。
  • 反解 plan_stroke 也按这面胶皮的 e、ks 去算，所以球员“知道”自己的胶皮特性。
  • “吃转”不需要特判：ks 小，来球旋转就不容易把球带偏（但旋转会大量保留下来）。
  • ks > 1 表示胶皮切向变形在离拍时回弹（切向恢复，Cross 2005），球的转速能超过“纯滚动”。反胶 ks 1.45、μ 1.2 是按实测转速标定的： 职业强力弧圈 100–130 转/秒（顶尖约 150），顶尖下旋发球 60–75 转/秒。

持拍手与握法

  • 左手（训练抽样 25%）：站位、够球、发球侧旋、所有动画整体左右镜像。左手发正手侧旋，侧旋方向和右手相反。
  • 直板（25%）：手指手腕灵活，台内小球误差 ×0.85、发球误差 ×0.88、发球迷惑性 ×1.1； 反手横打挥速 ×0.88、误差 ×1.12、旋转 ×0.9；传统推挡更稳（×0.92）。
  • 直板的推挡、搓和反手发球用正面胶皮（直板传统打法只用一面），反手横打才用背面。

动手看：同一个来球，五种胶皮挡回去

下面用和模拟器一模一样的碰撞公式在浏览器里算：来球 12 m/s 平飞，旋转可调；拍面略前倾、不挥拍（挡）或向前上方挥拍（拉）。

来球旋转： 上旋 150 rad/s

条形以中线为 0：向右是上旋，向左是下旋。长胶、防弧挡强上旋会回出下旋——这就是“倒转”，没有任何特判。

1.3球的飞行：重力 + 阻力 + 马格努斯

每个物理子步（1/240 s）做一次半隐式欧拉积分。

a = −KD·|v|·v + KM·(ω × v) − g // ω 为角速度（rad/s），g = 9.81
v ← v + a·dt    x ← x + v·dt    ω ← ω·(1 − 0.05·dt)

系数从哪来

KD = ½ρ·CD·A / m
KM = ½ρ·CM·V / m

ρ=1.2 kg/m³，球半径 20 mm，质量 2.7 g，CD=0.5、CM=0.6：K_D ≈ 0.14、K_M ≈ 0.0034。

量级对吗

转速 150 rad/s、球速 10 m/s 时马格努斯加速度约 0.0034×150×10 ≈ 5 m/s²，约半个 g： 强上旋明显“往下扎”、强下旋“往上飘”。旋转每秒衰减 5%，一个来回后仍有七成。

动手看：旋转怎么改变弧线

同样出手点、同样水平速度，只改旋转；竖直初速用二分求出，让三条球落在同一点——正是 plan_shot 做的事。

下旋 −120 rad/s 不转 0 上旋 +180 rad/s
旋转由“上旋量 top”和“侧旋量 side”两个标量生成：ω = top·(−v_y, v_x, 0)/|v_h| + side·(0,0,1)。 左手球员的侧旋在世界坐标里自动取反（side ×= hs）。

1.4碰撞：台面、球拍（胶皮）、网、台沿

台面

vz ← −Etable·vz  // E = 0.89
u = v水平 − ω × r  // 接触点滑动速度
jt = min(0.4·|u|, μ·(1+E)·vzin)  // μ = 0.25

上旋落台往前窜、下旋落台“刹车”，是冲量方程自然给出的结果。

球拍：能咬住球，还是打滑

u = v球 − v拍； jn = −(1 + e)·(u·n)
s = (u − r·ω × n) 的切向分量
jt = −min(ks·Kstick·|s|, μ·jn)·ŝ  // K_stick = 0.4，e/μ/ks 由胶皮决定
v ← v + jn·n + jt    ω ← ω − (n × jt)/(K·r)

切向速度小时 ks·K_stick·|s| 占优，胶皮“咬住”球；否则按库仑摩擦打滑。 出球旋转完全来自这次接触的切向冲量。实测（来球 12 m/s、上旋 150 rad/s；最后一行来球 8 m/s 不转），单位 rad/s：

1.6移动：会影响击球质量的步法物理

物理层只模拟和击球质量有关的三件事：到位时间、够球程度、重心方向。 “迈哪只脚、怎么迈”属于表现层，见第四部分的步法动画。

垫步（默认）

随时可变向；站稳后再起动有 0.3 s 的分腿垫步加速。

交叉步

动作第 11 维 >0.3 且横向输入大时触发：速度上限 ×1.5，但迈出后必须走完约 0.3 s，收不住。

重心预压

动作第 10 维把重心压向一侧：压对起动快，压错先移回来——假动作在物理上的作用点。

够球

手的可达范围是一个区间（自己视角）：正手横向 [−0.68, −0.08] m、反手 [−0.12, 0.45] m，向台内可探 1.1 m。 球在一个子步内走过的线段与手的距离 < 0.14 m 就算碰到。够到了但拉伸大，误差上升； predict 给出早点/晚点两个候选击球点，反应延迟之后才“看得见”。

1.7发球：两跳规则与八种手法

plan_serve_shot：外层二分水平速度 → 第二跳落在目标深度；内层二分竖直速度 → 第一跳落在本方台面离网 d1 处

抛球高度 0.3–1.8 m，抛得越高旋转越强、越难控制；奔球、急球固定低抛。发球时可以“回抛”藏动作，有 5% 被判违例。
击球点离台面 0.17–0.20 m；奔球、急球压到 0.12 m（约与网同高），第一跳压在本方端线附近，出球水平速度约 9–11 m/s，普通长球约 7.5 m/s，短球 4–5 m/s。

2.4发球战术脑：bandit，不是神经网络

score(k) = (wk + priork·N0)/(nk + N0) − λ·熟悉度(k)
P(k) = softmax(score(k)/τ)  // τ=0.06, N₀=4, λ=0.25；每分后 w,n ← 0.92·w,n 再累加

纯 PPO 很难在“发球类型”这种低频高方差维度上学出多样性，容易塌缩到一种发球。 手法与“下旋/不转/上旋”变化交给显式的多臂老虎机，重复使用会被预判；落点、力度、抛球高度、回抛仍由网络决定。

观测归一化与方差下限

运行均值/方差，裁剪 ±10。长期为常数的维度方差极小，一开就爆——热启动时用 --var-floor 57:65 给发球维度设下限。

动作均值边界惩罚

0.1·Σ max(|μ|−1,0)²：均值漂出 [−1,1] 后梯度消失，惩罚把它拉回来。

探索噪声夹紧

std ∈ [0.15, 0.35]：太小过早收敛成一种打法，太大只敢打保险球。

KL 早停

KL > 0.03 停本轮 epoch；log-ratio 夹在 ±20 防溢出。

3.2平衡：几次典型的“练歪了”

① 挡球一家独大

挡球借力、误差小，早期全场只挡。修法：来球太慢借不上力（NOPACE），被动挡慢球会送机会球。

② 全场只搓

“搓到超时”期望更高，每分 19 拍、65% 超时。修法：超时双方各 −1，连续搓球越来越容易冒高（幅度必须够大才有效）。

③ 发球直接得分率异常

训练与部署不一致：训练发球等待短、游戏长，接发方多站一秒走偏。训练等待拉宽到 0.15–1.8 s 后恢复正常。

④ 换了器材，旧模型就“不认识”

加入左右手、胶皮后，旧模型（看不到这些维度）左手对右手每分只有 3.15 拍，反手长胶胜率掉到 42–45%——这是必须重训的直接证据。

方法论：先关掉机制做 A/B（改 numba 常量必须清 __pycache__/*.nbi,*.nbc），用探针脚本量化行为变化，再决定要不要重训。

PART FOUR

四、画面渲染

pygame 只会画 2D，人物、球拍、球台全靠自己做透视投影和明暗；动画层只读物理状态，按资料里的动作要领摆姿势。

4.1相机与立体人物

相机

绕目标点旋转的透视相机（方位角、仰角、距离、焦距）。拖动旋转、滚轮缩放、C 复位。 球的轨迹按旋转类型着色，右下角小球窗口放大 10 倍显示旋转轴和转速。

Painter：深度排序的 3D 图元

  • 胶囊（四肢、躯干肩线）：沿轴向做 5 段平滑明暗渐变 + 圆头。
  • 球体（头、关节）：预渲染的径向渐变贴图，按半径和颜色缓存；头部叠头发。
  • 六面体（躯干、腰臀、鞋；裤腿是随大腿摆动的圆柱）：背面剔除，每个面按法线与光的夹角做 Lambert 明暗。
  • 圆盘（球拍）：有厚度的边、黑色正手面 / 红色反手面（职业选手最常见的配法），颗粒胶皮画颗粒点，长胶、防弧带色调。
  • 一盏斜上方主光 + 环境光 0.42；所有图元按到相机的深度从远到近画（画家算法）。

骨架

body_points 从物理状态（位置、速度、正反手 blend、重心、下蹲）推出骨架关节： 髋、肩、头、双脚（踩实不滑）、膝（两段 IK）、持拍臂（肩—肘—手两段 IK，肘的朝向由“肘极点”控制）、非持拍手配合。 左手球员所有横向量乘持拍手符号，整个人镜像；直板反手拍头朝下、拍柄更短。

4.2击球动作：按动作要领对齐

每种技术一组关键帧（引拍点、随挥点、转腰、下沉、肘位、拍面朝向，都在自己视角下）。 时间轴：击球前 0.5 s 开始引拍，最后 0.18 s 挥拍，击球后 0.12 s 随挥到位、0.5 s 内还原。 引拍和随挥都锚定在真实击球点上——无论球在哪，拍子都正好在击球那一帧碰到球。进攻技术的动作幅度随发力缩放。

技术资料里的动作要领动画里的对应
正手拉球重心在右脚，拍引到身体右后下方；蹬地转腰带臂，向前上方摩擦，随势挥到左额前引拍 (后 0.45, 外 0.3, 下 0.3)，随挥到额前上方，转腰 0.8
前冲弧圈引拍更靠后、更平，发力以向前为主，弧线低引拍更后更平，随挥偏前
提拉对付下旋：引拍更低，向上发力为主引拍低到 0.42，随挥向上
正手快攻小引拍，前臂快速收缩向左前方击打，结束在额前引拍 (后 0.22)，随挥到左前
反手拉球拍引到腹前左下方、肘在体前、手腕内收；以肘为轴向右前上方发力，随挥到右额前引拍在腹前、低于肩，肘前顶，随挥到右上方
撕反手近台，小引拍，借上旋快速向右前上方带小幅度、高速度
拧拉 / 霸王拧台内，拍头朝下、手腕内屈，由左后向右前上方拧专门的肘位和拍面朝向，霸王拧幅度更大
挡球 / 侧切拍面前倾，几乎不引拍，借力；侧切拍面半侧立向侧下切位移极小；侧切单独设定拍面
摆短 / 搓 / 劈长拍面后仰，向前下方触球；摆短动作最小，劈长前送最长三档幅度递增
削球远台，拍引到肩高，从上向前下方切削，随势到腹前引拍抬到 +0.55，随挥到 −0.45
扣杀高引拍，全身发力向前下方击打转腰最大 1.0
放高球远台，低引拍向上方挥送，把球送高送远随挥向上 0.7

练习页可以强制相持技术：接发方用选中的技术，发球方当陪练（削球、挡球对拉，放高球对扣杀，搓对搓），专门观察平时很少出现的动作。

4.3步法动画

脚平时踩实不动，离理想站位远了才迈步。每一步先按局面选步法，再生成“哪只脚、走多久、抬多高”的步子队列。

步法要领什么时候用
小碎步高频小垫步微调击球点快到击球、差一点点
单步一脚为轴，另一脚向来球方向迈一步距离小（<0.3 m）
并步一脚先向另一脚并半步，另一脚再向来球方向移，重心起伏小中等距离，时间充裕
跨步一脚蹬地，另一脚跨出一大步，重心压低，蹬地脚随后跟半步来球远、时间紧
跳步双脚几乎同时离地，离来球远的脚先落地高速大范围移动
交叉步远离来球的脚从体前交叉跨出，另一脚跟上物理层触发了交叉步
侧身步非持拍侧的脚先向反手位跨，持拍侧脚后撤，让出正手位用正手打反手位来球
救球先打再调整：击球时伸到极限，打完重心继续往外冲、压低，再碎步还原横向够到极限才击中
倒地爆冲正手大力拉冲时够到极限：身体几乎扑倒、单膝快着地，打完再爬起救球 + 正手进攻 + 大挥速

步法名会显示在球员脚下；救球和倒地爆冲用更醒目的标签。正常比赛里救球约占步法的 0.3–0.6%，倒地爆冲更少； 想专门看，在练习页选“相持技术 → 救球爆冲”：陪练连续压接球方正手大角，接球方横向起动慢半拍，只能伸到极限去够。
